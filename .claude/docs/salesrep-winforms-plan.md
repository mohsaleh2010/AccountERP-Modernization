# خطة شاشات المندوبين فى WinForms (هـ1) — 2026-10-25

**الهدف:** نظائر شاشات Razor الـ18 للمندوبين فى الديسك توب، دون إعادة كتابة أى منطق: كل المنطق فى `AccountModelsLib/SalesRep/*Service` وتستدعيه الشاشات مباشرة.

## القرارات
- الشاشات فى `Accounts/Sales_Rep_Frm` ومبنية بالكود بلا Designer (لا ملفات resx ولا تعارض ترميز).
- مظهر موحّد من `RepUi` (ألوان هادئة، Segoe UI، شبكة مخطّطة، أزرار مسطحة، RTL)؛ شاشات «قائمة + بطاقة» ترث `RepListEditFrm`.
- لا تغيير فى الخدمات؛ أى سلوك ناقص يُسجَّل لا يُعدَّل بصمت.
- ربط القائمة الرئيسية (`MainFrm_AccountUpdate*`، ترميز Windows-1256) فى دفعة منفصلة بتعديل على مستوى البايت، وبصلاحيات `SysConfigMenus` 985…999.
