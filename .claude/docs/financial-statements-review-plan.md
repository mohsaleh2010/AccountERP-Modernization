## الجزء ب — التصميم المستهدف
- **ب-1 محرك أرصدة للقراءة فقط** `LedgerBalanceEngine` (BusinessLibShared/GeneralLedger): استعلام واحد بلا جداول مؤقتة ولا قفل؛ لكل حساب ورقى (فترة، فرع، عملة): افتتاحى (من الجدول، عملة 0 أو العملة) + حركة قبل المدى + حركة المدى + ختامى؛ الحركة من `Account_Entry_Details`+`Account_Entry_List` (`Entry_No IS NOT NULL`، حدود نصف مفتوحة)؛ FULL JOIN وLEFT JOIN للأب. كل القوائم تُبنى منه بدوال نقية. **الآن.**
- **ب-2 جدول الأرصدة كاش مُتحقَّق منه**: «افتتاحى مشتق» = ختامى الفترة السابقة (حسابات النتيجة تُصفَّر وصافيها سطر «أرباح غير مقفلة»)؛ تنبيه انحراف وخيار «الافتتاحى: المخزَّن/المحسوب». لا كتابة. **الآن.**
- **ب-3 فحوص الثوابت** (شريط حالة + `/accounts/entries-integrity`): Σمدين=Σدائن (قيود/افتتاحى/حركة/ختامى)، ختامى الميزان = ميزانية + نتيجة، الأصول = الخصوم + الملكية، افتتاحى(ن+1)=ختامى(ن)، لا سطور على أب/يتيم، تصنيف Head/Follows متسق، تاريخ القيد داخل فترته. **الآن، تحذيرية.**
- **ب-4 إقفال الفترة 317/318 (لاحقاً بقرارك)**: حساب «أرباح مرحّلة» فى ربط الحسابات؛ معاينة ثم تنفيذ فى معاملة واحدة بشرط نجاح الفحوص؛ افتتاحى الفترة التالية لحسابات الميزانية فقط + صافى النتيجة على الأرباح المرحّلة؛ سجل فى جدول جديد `Account_Period_Close`؛ إدراج للفترة التالية فقط إن كانت خالية وإلا توقف وطلب موافقة؛ 318 = إعادة حساب فترة واحدة بمعاينة فروق.
- **ب-5 لاحقاً**: تجميع الفروع، إعادة تقييم العملات، قوائم مقارنة، تجميد قائمة معتمدة.
