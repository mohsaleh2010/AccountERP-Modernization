### (ب) التشغيل لدى الغير / للغير (فى مشروع `Accounts`)
- **تشغيل خارجى** `Accounts\Work_Out\` و**تشغيل للغير** `Accounts\Work_In\`: إرسال واستلام طلبيات، مبيعات هالك، وتقارير أرصدة عند الموردين/العملاء.
- جداول `Work_Out_Details*` و`Work_In_Details*`: أرصدة مستقلة عن `Unit_item`.
- ملاحظة: نسخة `ProductionsRates\Work_Out\` مستبعدة من البناء؛ الحية هى `Accounts\Work_Out`.

### (ج) إنتاج النسيج (`ProductionsRates`) — نشاط مستقل
ورديات، أوامر تشغيل الماكينات، إنتاج النسيج (وبرة/لحاف)، معدلات الإنتاج اليومية، العطلات، صيانة الماكينات، المطواة/السدا/المبرزاتى، رسمات الأصناف، التطريز. **أغلبه إنتاجية عمال وماكينات وأجور، لا حركة مخزن.**
عناصر «حسابات خاصة» (النزلات، حساب الشركاء) مالية لا إنتاجية.

## 2) التصميم المقترح (للمجموعة أ — التصنيع العام)

### 2.1 دورة أمر الإنتاج (Manufacturing Order)
```text
مسودة ← مُعتمد ← تحت التشغيل ← مكتمل ← مغلق
  1) الاعتماد: المنتج + الكمية المخططة + BOM (نسخة من مكونات الصنف تُحفظ مع الأمر وتقبل التعديل)
  2) صرف الخامات: إذن 1010 «صرف إلى الإنتاج» مربوط بالأمر (كلى أو على دفعات) ← IssuedQuantity
  3) استلام المنتج: إذن 1009 «استلام من الإنتاج» مربوط بالأمر (كلى أو جزئى) ← ReceivedQuantity
  4) الإغلاق: مقارنة المستهلك الفعلى بالمعيارى (فروق الخامات)، احتساب تكلفة المنتج
```
- يُبنى فوق `WorkOrderList`/`WorkOrderDetail` القائمين (لا جداول بديلة). **قرارك: الخامات نوع سطر فى `WorkOrderDetail`** — عمود جديد `Line_Type` (1 منتج / 2 خامة)، و`RequiredQuantity` = المعيارى، و`IssuedQuantity` = المصروف للخامة، و`ReceivedQuantity` = المستلم للمنتج (الأعمدة موجودة).
- **الاستلام السريع الحالى** («استلام بالخامات» بلا أمر) يبقى كمسار مختصر = أمر إنتاج يُعتمد ويُصرف ويُستلم ويُغلق فى خطوة واحدة.

### 2.2 تكلفة الإنتاج (توافقاً مع خطة 01)
```text
تكلفة المنتج المستلَم = Σ (كمية الخامة المصروفة × تكلفتها وقت الصرف من DPIE) + تكاليف إضافية (اختيارى: أجر/تحميل ثابت لكل وحدة)
تكلفة الوحدة = التكلفة ÷ الكمية المستلَمة  ← تدخل المتوسط عند الاستلام (Updates_Avg_Cost)
```
- الاستلام الجزئى: تكلفة مؤقتة بالمعيارى، وتُسوّى عند الإغلاق (فرق التكلفة على آخر استلام أو كتسوية قيمة).
- ما دام الجرد الدورى فعّالاً (م-01-1) لا قيود WIP، وتُعرض «تحت التشغيل» كتقرير (مصروف خامات لأوامر غير مغلقة) يغذّى `Financial_Period_Stores_Balance` (UnderWorkingMaterial). عند تفعيل الجرد المستمر تُقيَّد WIP تلقائياً حسب مصفوفة خطة 01 §2.8 (صرف للإنتاج: WIP / خامات، استلام: تام / WIP).

### 2.4 المجموعة (ب): التشغيل لدى الغير وللغير (ضمن النطاق بقرارك)
**الفكرة:**
- **التشغيل لدى الغير:** مورد التشغيل الخارجى = **مخزن خارجى له طرف** (نفس نمط سيارة المندوب) بأذون موجودة: `SarfToOuterStore_15` و`EstlamFromOuterStore_14`.
- **التصنيع للغير:** يبقى على جداول `Work_In` الحالية بقرارك (م-05-6)، لأن البضاعة ملك العميل. (المتبع حديثاً تتبّعها فى نفس المخزون بعلامة «المالك = العميل» — استثناء مقصود.)

| الشاشة الحالية | فى Razor |
|---|---|
| إرسال/استلام طلبية تشغيل خارجى (`Add_Requests_Work_Out`، `Receive_Requests_Work_Out`) | طلبية تشغيل خارجى ← إذن صرف لمخزن المورد الخارجى ← استلام منتج بعد التشغيل (تكلفة = تكلفة المرسل + أجر التشغيل من فاتورة المورد) |
| مبيعات هالك تشغيل خارجى (`Receive_Destruction_Work_Out`) | إذن استلام هالك + بيعه بفاتورة |
| تقارير المرسل/المستلم/أرصدة عند الموردين | من الدفتر (DPIE) لمخازن الموردين الخارجية |
| تشغيل للغير: استلام/إرسال طلبية، مبيعات هالك، التقارير (`Accounts\Work_In`) | **بقرارك: على جداول `Work_In` الحالية** بشاشات Razor، بلا ربط بالمحرك (بضاعة العميل ليست مخزون الشركة) + فاتورة أجر التصنيع كما هى |

- **ترحيل الأرصدة القديمة (التشغيل الخارجى فقط):** أرصدة `Work_Out_Details_Balance` الحالية تُنقل كرصيد أول مدة لمخازن الأطراف الخارجية (خطة 02) بعد مراجعة.

### 2.5 المجموعة (ج): إنتاج النسيج (ضمن النطاق بقرارك)
**الملاحظة الحاكمة:** النسيج يحمل **نظام أرصدة موازياً** — أرصدة الأقسام فى `Textile_Item_Dept_Balance` (فحص، تشطيب، تطريز) وشاشات «إرسال الأصناف إلى…» بين الأقسام.
**التوافق المقترح:** **كل قسم إنتاج = مخزن** من نوع «قسم» (نوع الطرف 20 موجود فى الأذون)، فيصبح النقل بين الأقسام **إذن تحويل عادياً** عبر المحرك، والرصيد فى `Unit_item` كبقية النظام. لا رصيد موازٍ. (`Textile_Item_Dept_Balance` و`Order_Working_Textile` فارغان فى قاعدة التطوير.)

| المجموعة | الشاشات (ProductionsRates) | فى Razor |
|---|---|---|
| بيانات أساسية | ماكينات النسيج والتطريز، الورديات (`Wardiat`)، العطلات (`AtalatListFrm`)، بيانات المطواة (`Matwa_ListFRM`)، رسمات الأصناف (`ItemProductionData_ListFRM`) | صفحات بيانات أساسية بنفس النمط المبنى |
| أوامر التشغيل | `NewOrderWork_FRM`، `OrderWorkListFRM` (تشغيل ماكينة بصنف) | تُدمج مع أوامر الإنتاج §2.1 بنوع «أمر نسيج» (ماكينة + صنف قديم/جديد) |
| إدخال الإنتاج | `Textile_Production_Rates_New`، إنتاج الوبرة/اللحاف من أمر التكليف (3 نسخ متقاربة) | صفحة واحدة «إدخال إنتاج النسيج» بنوع المنتج، تنشئ **استلام إنتاج** للقسم + سطور معدلات العمال |
| معدلات وكفاءة | معدلات العمال، الكفاءة اليومية وبالفترة للوبرة واللحاف، التطريز (`EmpProductionRate_`) | تقارير Razor من بيانات الإنتاج (لا حركة مخزن) |
| السدا والمبرزاتى | إنتاج السدا/المبرزاتى، إرسال المطواة للماكينات، أرصدة أصناف المطواة | المطواة صنف؛ الإنتاج استلام إنتاج والإرسال تحويل لقسم النسيج |
| أقسام ما بعد الإنتاج | الفحص (`Fa7s_Dept`)، التشطيب (`Tashteeb_Dept`)، التطريز (`Tatreez_Dept`)، الاستلام من الإنتاج (`EstlamProduction`) | أقسام = مخازن؛ «إرسال إلى» = تحويل؛ «تحليل الأصناف» = تغيير هوية صنف (فرز درجات) |
| صيانة الماكينات | قائمة وعمليات الصيانة | صفحتان + صرف قطع الغيار بإذن 1022 الموجود |
| حسابات خاصة | النزلات (`Capita_frm`، `tottalof_nazlla`)، الشركاء (`Capital_frm`، `CapitalFRM`) | **مالية لا إنتاجية**: تُحوَّل مع شاشات الحسابات (بنفس محرك النقدية) — مرحلة أخيرة |

- **التكرار:** نسخ الشاشات المتقاربة (ثلاث نسخ «إنتاج الوبرة من أمر التكليف») تُدمج فى صفحة واحدة بعد مقارنة الحقول.

## 6) الاختبار
- صرف خامات لأمر ← رصيد الخامات ينقص، `IssuedQuantity` يزيد، DPIE بتكلفة الخامة.
- استلام منتج ← رصيده يزيد، متوسطه = تكلفة الإنتاج المحسوبة.
- الإغلاق ← فروق المعيارى صحيحة، والأمر لا يُعدَّل بعده.
- الاستلام السريع = نفس النتيجة بخطوة واحدة.
