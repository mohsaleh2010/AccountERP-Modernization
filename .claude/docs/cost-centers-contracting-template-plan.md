# خطة: قالب ربط المقاولات + ربط حساب أب بكل أبنائه دفعة واحدة (متمم المرحلة 2)

**التاريخ:** 2026-10-31 — **الحالة:** خطة فقط (لم يُنفَّذ). مؤجَّلان من م2 فى `cost-centers-razor-plan.md`.
**القاعدة الثابتة:** إضافة فقط؛ لا UPDATE/DELETE لروابط قائمة (`Cost_Center_ForAccounts`)؛ المكرر يُتخطى.

## أ) ربط حساب أب بكل أبنائه (يُبنى أولاً — القالب يعتمد عليه)
1. **تحقق قبل الكود:** هيكل الأب/الابن فى الحسابات — `Submain_Account.Main_Account_Id` يشير لحساب رئيسى (`Main_Accounts`)؛ تحديد هل الشجرة متعددة المستويات وكيف تُجلب كل الأوراق تحت أب (CTE على `Main_Accounts` أو `SubAccount_NO` بالبادئة). يُقرأ من `ERP_V1_3.md` + `AccountsTreeList` قبل أى سطر.
2. **خدمة:** `CostCenterService.LeafAccountsUnder(opp, mainAccountId)` (أوراق `IS_Last_Level=1` تحت الأب بكل مستوياته) + `BulkLinkUnderParent(opp, parentIds, centerIds)` تستدعى `BulkLink` الموجودة (تخطى المكرر، أوراق المراكز فقط).
3. **واجهة** (تبويب «بحسب المركز» فى `CostCenterForAccountsList`): بجانب البحث عن حساب، زر «إضافة كل أبناء حساب أب» → منتقى شجرة الحسابات (`AccountTreePicker`) → معاينة العدد («سيُربط 37 حساباً بـ3 مراكز، منها 5 مربوط مسبقاً») → تأكيد → تنفيذ → ملخص (أُضيف/تُخطى).
4. **اختبار:** عدد صفوف `Cost_Center_ForAccounts` بعد = قبل + الجديد فقط؛ إعادة التنفيذ لا تضيف شيئاً.

## ب) قالب ربط المقاولات
**يحتاج منك تحديد** حسابات المصروفات المباشرة لأربع فئات: (1) مواد (2) أجور (3) مقاولو باطن (4) معدات — حساب أب لكل فئة (أو قائمة حسابات) من شجرة حساباتك، وهل تُضاف «مصروفات عامة» و«إيراد المستخلصات».
1. **تخزين التعيين:** جدول إعداد صغير جديد `Cost_Center_Template_Map` (TemplateKey, Category, Main/Submain Account_Id) — أو مفاتيح `SysConfig` — يُملأ من شاشة «إعداد قالب المقاولات» (يختار المستخدم حساب الأب لكل فئة، لا أرقام ثابتة فى الكود).
2. **التطبيق:** زر «طبّق قالب ربط» على مشروع (`Cost_Type=1`) → يربط حسابات كل فئة (بالوراثة من أ) بمراكز المشروع الورقية من نوع «بند تكلفة» (يوافق فئة)، ويضبط سياسة الحسابات المختارة «إلزامى» **بعد سؤالك** (تعديل سياسة = تغيير سلوك، فيكون خيارًا صريحًا لا تلقائيًا).
3. **قالب شجرة المشروع** (مراحل + بنود: مواد/أجور/مقاولو باطن/معدات) يُنشأ مع «نسخ قالب مشروع» المؤجَّل من م1؛ القالب هنا يربط ما أُنشئ.
4. **معاينة قبل التنفيذ** + تقرير بعده؛ كله عبر `BulkLink` (إضافة فقط).
5. **اختبار:** مشروع تجريبى «برج النخيل» ← تطبيق القالب ← قيد مصروف مواد على بند المواد مقبول وعلى بند الأجور يُحذَّر (CCLINK).

## ترتيب التنفيذ المقترح
أ.1 (فحص الهيكل) ← أ.2-4 ← تحديدك لحسابات الفئات ← ب.1-5. كل خطوة مهمة مستقلة ثم `/clear`.
