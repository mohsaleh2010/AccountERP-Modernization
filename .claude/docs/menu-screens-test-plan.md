# خطة اختبار شاشات القوائم (Razor) — شاشة بشاشة — 2026-11-07

**الأساس:** كل الروابط من `@page` الفعلية فى `Razors/AccountERP.SharedUI/Pages`. القائمة الجانبية تُبنى من جدول `SysConfigMenus`
(حسب صلاحيات المستخدم)، فأسماء القوائم هنا هى الأسماء المعتمدة فى `menu-*-razor-plan.md` و`main-menu-screen-map.md`،
وقد يختلف نصّ العنوان عندك قليلاً حسب ما ضبطته فى «ترتيب القوائم». الشاشة التى تظهر «قريباً» فى القائمة = غير مربوطة بـ `RazorPath` (افتحها بالرابط مباشرة).

**رابط الموقع محلياً:** `http://localhost:5256` (مشروع `AccountERP.Web`) + الرابط المذكور فى كل صف.

**رموز الحالة:** ⬜ لم يُختبر ✅ نجح ⚠️ بملاحظة ❌ فشل

---

## 0) قواعد عامة تُطبَّق على كل شاشة

| # | القاعدة |
|---|---|
| ع-1 | افتح الشاشة من القائمة الجانبية (لا بالرابط فقط) وتأكد أنها تفتح بلا «قريباً» وبلا أخطاء حمراء |
| ع-2 | افتحها بحساب **Admin** ثم بحساب محدود الصلاحية: يجب أن تختفى/تُمنع الشاشة بلا صلاحية (نظام `PERMATIONS` مؤثر فعلاً) |
| ع-3 | الحفظ: أدخل بيانات صحيحة ← رسالة نجاح ← **أعد تحميل الصفحة (F5)** فتبقى البيانات |
| ع-4 | التحقق: اترك حقلاً إلزامياً فارغاً/أدخل قيمة سالبة أو مكررة ← رسالة خطأ واضحة بلا حفظ |
| ع-5 | الحذف: صف مستخدم فى عمليات ← يُمنع برسالة؛ صف جديد غير مستخدم ← يُحذف بعد تأكيد |
| ع-6 | الفواتير/الأذون: سجّل `Unit_Item.Full_Qua` قبل وبعد (بيع ينقص، مرتجع بيع يزيد، شراء يزيد، مرتجع شراء ينقص — لكل مخزن) |
| ع-7 | أى عملية مالية: افتح «مراجعة القيود» وتأكد أن القيد متوازن (مدين = دائن) وبتاريخ داخل فترة مالية مفتوحة |
| ع-8 | نصوص عربية: تظهر سليمة (لا `?` ولا رموز مشوهة) بعد الحفظ والتحميل |
| ع-9 | لا تعدّل/تحذف بيانات إنتاج قائمة؛ استخدم بيانات اختبار بأسماء تبدأ بـ «اختبار-» لتسهل إزالتها |

## 1) الترتيب المقترح للاختبار (لأن بعض الشاشات تعتمد على غيرها)

1. **ملف** (دخول، مستخدمون، صلاحيات، ربط الحسابات، ضرائب)
2. **بيانات أساسية** (فروع، مخازن، صناديق/بنوك، عملاء، موردون…)
3. **الحسابات ← الإعداد** (شجرة الحسابات، فترات مالية، عملات، مراكز تكلفة)
4. **الأصناف** (وحدات، فئات، أصناف، أسعار) ثم **أرصدة أول المدة**
5. **المخازن** (أذون، تحويلات)
6. **المشتريات** ثم **المبيعات**
7. **الحسابات ← النقدية والكشوف** ثم **القيود** ثم **الحسابات الختامية** (تقرأ كل ما قبلها)
8. **المندوبون** ثم **السيارات**

بعد كل مجموعة: افتح «ميزان المراجعة» `/accounts/final/trial-balance` وتأكد أنه متوازن.

## 14) ملاحظات صدق

* **ما لم أتحقق منه:** الحقول الدقيقة لكل شاشة (قرأتُ أسماء الصفحات ومساراتها وخطط الشاشات، ولم أفتح كل صفحة سطراً بسطر). إن اختلف حقل عندك فالمرجع هو الشاشة.
* **أسماء القوائم** تأتى من قاعدة البيانات (`SysConfigMenus`)؛ لم أستطع قراءتها (سلاسل الاتصال أسرار)، فاعتمدتُ أسماء الخطط. إن أردت أن أُضيف عمود «ID القائمة» الحقيقى فأحتاج منك لقطة من القائمة أو مخرجات استعلام.
* **الربط الفعلى بالقائمة:** أى شاشة لها `@page` لكن `RazorPath` فارغ ستظهر «قريباً» فى القائمة؛ سجّلها فى عمود الملاحظات.
* هذه الخطة تكمل (لا تلغى) `master-user-test-plan.md` و`pending-tests-all.md`، وتُرتَّب حسب القوائم بدل المواضيع.
